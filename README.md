# Water Splash

スマホ縦画面向けの、写真に向かってホースの水をかけるようなCanvasエフェクトのプロトタイプです。

## GitHub Pagesで公開

1. GitHubで新しいリポジトリを作成
2. このフォルダの中身をアップロード
3. Settings → Pages
4. Sourceを「Deploy from a branch」
5. Branchを `main` / `root` に設定
6. 保存後、表示されたURLをスマホで開く

## 操作

- 画面をタップ：中央奥からタップ位置へ水流
- 水量スライダー：水流の太さ・粒子量・飛沫量を変更
- 背景を変更：スマホ内の写真を背景に設定
- リセット：水エフェクトを消去

## 注意

初期 `background.png` はアプリのイメージ確認用です。
